# Exemple SAS — Site vitrine (démo)

⚠️ Ce projet est une version **démo publique**.
Les informations (nom, email, téléphone, société) sont fictives.

## Objectif
Démontrer la création d’un site vitrine statique professionnel en HTML, CSS et JavaScript.

## Fonctionnalités
- Navigation multi-pages
- Design responsive (desktop / tablet / mobile)
- Menu hamburger
- Contact via mailto / tel
- Pages légales (démo)

## Stack
- HTML5
- CSS3 (responsive, flex, grid)
- JavaScript (vanilla)

## Auteur
Démo publique — informations fictives
